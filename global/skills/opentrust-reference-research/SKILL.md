## When to Use This Skill

When domain knowledge, architecture patterns, or reference material is needed during any workflow phase.

## Workflow

1. Identify the knowledge need and map to selectors (CTX/SK/B/DOC).
2. Request synthesis using approved selectors from the task contract.
3. Receive synthesized, actionable knowledge from the Knowledge team.
4. Cite source IDs (CTX, SK, B, DOC) in outputs. Do not include raw chunks.

## Output

- Synthesized reference response with source IDs
- Selector verification report

## Rules

- Only the Knowledge team calls the Retrieval Provider.
- No raw book content, excerpts, or internal library names in versioned files.
- Use only selectors approved in the task contract.
- Reference `docs/opencode/OPERATIONAL_RETRIEVAL_MAP.md`.
