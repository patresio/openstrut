# Task Plans Directory

This directory stores active repository-local Task Plans.

- Task Plans are created only after the Approval Gate for mutating tasks.
- Read-only requests do not create Task Plans.
- The preferred filename is `<task-id>.md`.
- Exactly one active state and one next action must be maintained.
- Completed durable knowledge must be transferred to canonical project documentation.
- The project may define its own archival policy for completed plans.

*Note: This README is not an active Task Plan.*
