# Commit Convention References Manifest

These files are read-only research material demonstrating common commit conventions.
**Note: These references do not define a mandatory global commit convention for the harness.**

## Files

* `README.md`
  * **Subject:** Semantic commit types with emojis.
  * **Source/Provenance:** Unknown (Portuguese documentation on Conventional Commits).
  * **Intended Use:** Example of a detailed project-specific commit policy.

* `conventional-commits.md`
  * **Subject:** Conventional Commits 1.0.0 specification.
  * **Source/Provenance:** [Conventional Commits](https://www.conventionalcommits.org/).
  * **Intended Use:** Standard structural reference for semantic versioning commits.

* `commit-msg.sh`
  * **Subject:** Git hook for commit message validation.
  * **Source/Provenance:** Unknown.
  * **Intended Use:** Example of enforcing commit conventions programmatically.

* `prepare-commit-msg.sh`
  * **Subject:** Git hook for preparing commit messages.
  * **Source/Provenance:** Unknown.
  * **Intended Use:** Example of Git integration for commit messages.

* `push.sh`
  * **Subject:** Shell script wrapping git push.
  * **Source/Provenance:** Unknown.
  * **Intended Use:** Example of a deployment or delivery helper script.
