# Engineering Plan

**Purpose:** Perform read-only exploration and planning for a given objective.

## Instructions
1. Inspect applicable global and project-local instructions, and relevant repository evidence.
2. If useful, delegate read-only work to the `explore` or `scout` agents. Do not delegate to mutating agents.
3. Produce a plan containing: scope, exclusions, alternatives, risks, acceptance criteria, ordered microincrements, validation strategy, and delivery strategy.
4. Stop at the Approval Gate to present the plan.
5. Do not mutate any files, do not create a Task Plan, do not create any branches, issues, commits, pushes, or PRs, and do not implement any code.
6. If prerequisites cannot be met, stop and provide a factual report.
